Метод принимает левую и правую границу (a и b) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал true, если num входит в указанный диапазон (включая границы). Обратите внимание, что отношение a и b заранее неизвестно (неясно кто из них больше, а кто меньше).

**Пример 1:**  
a=5, b=1, num=3 → true  

**Пример 2:**  
a=2, b=15, num=33 → false  

**Алгоритм решения**

1. Найти минимальную и максимальную из границ: `min = Math.min(a, b)`, `max = Math.max(a, b)`.
2. Проверить условие `num >= min && num <= max`.
3. Вернуть результат проверки.

```java
public boolean isInRange(int a, int b, int num) {
    int min = Math.min(a, b);
    int max = Math.max(a, b);
    return num >= min && num <= max;
}

**Пример 1:** x=1111 → true  
**Пример 2:** x=1211 → false  

**Алгоритм решения**

1. Взять абсолютное значение числа.
2. Запомнить последнюю цифру (`x % 10`).
3. В цикле while делить число на 10 и сравнивать каждую новую последнюю цифру с запомненной.

```java
public boolean equalNum(int x) {
    x = Math.abs(x);
    if (x < 10) {
        return true;
    }
    int digit = x % 10;
    while (x > 0) {
        if (x % 10 != digit) {
            return false;
        }
        x /= 10;
    }
    return true;
}

Метод запускается до тех пор, пока пользователь не угадает число. После этого выведите на экран количество попыток, которое потребовалось пользователю, чтобы угадать число.

**Пример:**  
Введите число от 0 до 9:  
5  
Вы не угадали, введите число от 0 до 9:  
9  
Вы угадали!  
Вы отгадали число за 2 попытки  

**Алгоритм решения**

1. Сгенерировать случайное число от 0 до 9 (`Random.nextInt(10)`).
2. В цикле while запрашивать число у пользователя (с проверкой корректности ввода).
3. Увеличивать счётчик попыток.
4. При совпадении вывести сообщение об успехе и количество попыток, затем выйти из цикла.
5. При несовпадении — предложить ввести число снова.

```java
public void guessGame() {
    Random random = new Random();
    int secret = random.nextInt(10);
    Scanner sc = new Scanner(System.in);
    int attempts = 0;

    System.out.println("Я загадал число от 0 до 9. Попробуйте угадать!");
    while (true) {
        System.out.print("Введите число от 0 до 9: ");
        while (!sc.hasNextInt()) {
            System.out.print("Ошибка ввода. Введите целое число от 0 до 9: ");
            sc.next();
        }
        int guess = sc.nextInt();
        attempts++;

        if (guess < 0 || guess > 9) {
            System.out.println("Число должно быть от 0 до 9. Попробуйте ещё раз.");
            continue;
        }

        if (guess == secret) {
            System.out.println("Вы угадали!");
            System.out.println("Вы отгадали число за " + attempts + " попытки");
            break;
        } else {
            System.out.println("Вы не угадали, введите число от 0 до 9:");
        }
    }
}
```

**Текст задачи**

Дана сигнатура метода: `public void reverse (int[] arr);`  
Необходимо реализовать метод таким образом, чтобы он изменял массив arr. После проведённых изменений массив должен быть записан задом-наперёд.

**Пример:**  
arr=[1,2,3,4,5] → arr=[5,4,3,2,1]  

**Алгоритм решения**

1. Пройти циклом от начала массива до середины.
2. На каждой итерации поменять местами элемент `arr[i]` и `arr[n-1-i]` (через временную переменную).
3. Массив изменяется «на месте» (in-place).

```java
public void reverse(int[] arr) {
    if (arr == null) return;
    int n = arr.length;
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }
}
```

**Алгоритм решения**

2. Заполнить его: `result[i] = arr[n-1-i]`.
3. Вернуть новый массив (исходный не изменяется).

```java
public int[] reverseBack(int[] arr) {
    if (arr == null) return null;
    int[] result = new int[arr.length];

        result[i] = arr[arr.length - 1 - i];
    }
    return result;
}
```

arr1=[1,2,3], arr2=[7,8,9] → [1,2,3,7,8,9]  

**Алгоритм решения**

1. Создать новый массив длиной `arr1.length + arr2.length`.
2. Скопировать элементы arr1 в начало результата.
3. Скопировать элементы arr2 в оставшуюся часть (начиная с индекса `arr1.length`).
4. Вернуть новый массив.

```java
public int[] concat(int[] arr1, int[] arr2) {
    if (arr1 == null) arr1 = new int[0];
    if (arr2 == null) arr2 = new int[0];
    int[] result = new int[arr1.length + arr2.length];
    System.arraycopy(arr1, 0, result, 0, arr1.length);
    System.arraycopy(arr2, 0, result, arr1.length, arr2.length);
    return result;
}
```

### Задача 4 (№9). Все вхождения

**Текст задачи**

Дана сигнатура метода: `public int[] findAll (int[] arr, int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны индексы всех вхождений числа x в массив arr.

**Пример:**  
arr=[1,2,3,8,2,2,9], x=2 → [1,4,5]  

**Алгоритм решения**

1. Пройти по массиву и собрать все индексы, где `arr[i] == x` (например, в ArrayList).
2. Создать массив целых чисел нужного размера и скопировать в него собранные индексы.
3. Вернуть этот массив.

```java
public int[] findAll(int[] arr, int x) {
    if (arr == null) return new int[0];
    ArrayList<Integer> indices = new ArrayList<>();
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) {
            indices.add(i);
        }
    }
    int[] result = new int[indices.size()];
    for (int i = 0; i < indices.size(); i++) {
        result[i] = indices.get(i);
    }
    return result;
}
```

### Задача 5 (№10). Удалить негатив

**Текст задачи**

Дана сигнатура метода: `public int[] deleteNegative (int[] arr);`  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором записаны все элементы массива arr кроме отрицательных.

**Пример:**  
arr=[1,2,-3,4,-2,2,-5] → [1,2,4,2]  

**Алгоритм решения**

1. Подсчитать количество неотрицательных элементов.
2. Создать новый массив этой длины.
3. Пройти исходный массив ещё раз и скопировать в результат только элементы `>= 0`.
4. Вернуть новый массив.

```java
public int[] deleteNegative(int[] arr) {
    if (arr == null) return new int[0];
    int count = 0;
    for (int v : arr) {
        if (v >= 0) count++;
    }
    int[] result = new int[count];
    int j = 0;
    for (int v : arr) {
        if (v >= 0) {
            result[j++] = v;
        }
    }
    return result;
}
```
